# prompt/ — 模型交接提示词包

> 本目录是「换 AI 模型 = 数据迁移」的工程化方案。
> 每次换新模型时，把 `01-handoff.md` 整段发给它，即可无缝继续教学。

## 文件地图

| 文件 | 职责 | 更新频率 | 谁看 |
|---|---|---|---|
| `01-handoff.md` | 给新模型的冷启动消息（角色激活 + 状态快照） | 每次会话后刷新快照 | 新模型 + 你 |
| `02-ta.md` | TA 人设、教学原则、格式规范 | 极少 | 模型 |
| `03-profile.md` | 学生档案（背景/目标/已掌握/薄弱点） | 低频（掌握项变化时） | 模型 |
| `04-progress.md` | 进度表 + 下一步 + Lab 复盘 | ★每次会话结束 | 模型（权威状态） |
| `05-resources.md` | 资料索引（书/讲义/源码/命令/环境事实） | 环境变化时 | 模型 |
| `06-protocol.md` | 会话协议、状态版本机制、更新规则 | 极少 | 模型 + 你 |
| `07-pitfalls.md` | 反复错误与踩坑档案 | ★每次会话结束 | 模型（重点盯） |

## 迁移步骤（换模型时）

1. 新模型对话框第一句 = 复制 `01-handoff.md` 全文。
2. 它会按指示读 02-07。若它读不到文件，把对应文件内容直接贴给它。
3. 开课前先让它复述一遍「当前进度 + 下一步 + 薄弱点」，验证它没读错。

## 更新义务（每次会话结束时）

1. 更新 `04-progress.md`（进度表、下一步勾选、最近会话记录）。
2. 更新 `07-pitfalls.md`（新坑、复发计数）。
3. 刷新 `01-handoff.md` 底部状态快照的版本日期。
4. 各文件头部版本行改成当天日期。

## 与 note/ 的关系

- `note/` = 阅读笔记与历史档案（Lab0.md、学习日志、Lec/*）。
- `prompt/` = 模型交接知识库（权威、结构化、给 AI 看）。
